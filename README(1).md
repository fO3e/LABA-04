# Лабораторная работа №4, вариант 10

## Состав

- `lab04-mergesort-linear-heapsort.py` - реализации, тесты, замеры и графики;
- `lab04-report.md` - отчёт, таблица свойств и выводы;
- `results/benchmark_results.csv` - результаты всех измерений;
- `results/benchmark_graphs.png` - log-log графики.

## Требования

- Python 3.10+;
- `matplotlib` для построения графика.

## Запуск

```bash
python lab04-mergesort-linear-heapsort.py --variant 10 --out results
```

Сначала выполняется `self_check`. Если хотя бы одна проверка не пройдена,
бенчмарк не запускается.
